# 스쿨팟 · 안남중학교

창원 안남중학교 학생들이 학교생활과 이야기를 나누는 모바일 커뮤니티입니다. Vite + HTML/CSS/JavaScript ES Modules + Supabase를 사용합니다.

현재 아이디 계정용 DB 마이그레이션과 accounts/neis/delete-account Edge Function이 실제 Supabase 프로젝트에 적용되어 있습니다. 실제 가입·로그인·글·댓글·투표·알림·수행평가·급식·복구·탈퇴까지 검증했습니다. 공개 사이트는 https://codexora-dev.github.io/SchoolPot/ 입니다. main의 프론트엔드 변경은 검사 후 자동 배포합니다.

## 가입과 로그인

- 이메일을 입력하거나 인증할 필요가 없습니다.
- 가입 때 관리자 설정의 본인 학년·반을 선택합니다. 개인정보 동의·연령 체크를 요구하지 않고 확인 기록도 임의 생성하지 않습니다. 소속은 자기 신고이며 재학생 인증이 아닙니다. 반 변경은 관리자 정정으로만 처리합니다.
- 아이디는 영문자로 시작하는 영문·숫자·밑줄 3~20자이며 대소문자를 구분하지 않습니다.
- 비밀번호는 8~128자입니다. Supabase Auth에서 해시로 관리하며 앱 DB에 비밀번호를 저장하지 않습니다.
- 가입 직후 프로필이 자동 생성됩니다. 닉네임은 프로필 화면에서 변경할 수 있습니다. 수행평가는 저장된 본인 학년도·학년·반으로만 접근합니다.
- 가입 때 한 번 표시되는 256비트 복구 코드를 보관하세요. 이메일 없이 비밀번호를 재설정할 때 필요합니다. 복구 후에는 새 코드가 발급되고 이전 코드와 세션은 무효화됩니다.
- 재학생 여부는 확인하지 않습니다. 학생증·학번·실명을 수집하지 않습니다.
- 로그인 화면의 자동로그인을 선택하면 브라우저를 다시 열어도 로그인 상태를 복원합니다. 미선택 시 현재 탭에서만 유지하며, 비밀번호 자체는 저장하지 않습니다. 저장 차단 환경에서는 자동로그인 유지 불가 안내를 표시합니다.
- 비밀번호 입력창 오른쪽의 눈 아이콘으로 표시·숨기기를 전환합니다. 로그인·가입·재설정·변경·탈퇴 확인에 공통 적용됩니다.
- 계정 메뉴 → 계정 관리 · 회원탈퇴에서 현재 비밀번호와 확인 문구를 입력해 탈퇴합니다. 계정·소속·동의·세션과 계정 연결 작성 내용을 삭제합니다. 본인 게시글의 답글도 함께 삭제될 수 있습니다.

**운영 설정:** 관리자에서 학년별 반 수와 소속 정정을 관리합니다. 현재 실제 반 수 [7,7,7]을 유지합니다. 문서 검토 상태는 가입 차단과 별개입니다. 사용자 요청으로 개인 이메일과 지정된 공개 안내 섹션을 제거했습니다. 이는 법적 운영 검토 완료를 의미하지 않습니다. [반별 권한·개인정보 안내](docs/classes-privacy.md)를 참고하세요.

## 로컬 실행

Node.js 22.12 이상이 필요합니다. 프로젝트 폴더에서 아래 명령을 실행하세요.

    npm ci
    npm run dev

기본 주소는 http://127.0.0.1:5173/ 입니다. 이미 설정된 .env.local은 덮어쓰지 마세요. 새 체크아웃에서는 .env.example을 .env.local로 복사하고 공개 키를 입력합니다.

    VITE_SUPABASE_URL=https://hlglstdtgcodblynicmh.supabase.co
    VITE_SUPABASE_PUBLISHABLE_KEY=프로젝트의_publishable_키
    VITE_SCHOOL_NAME=안남중학교

VITE_ 변수는 브라우저에 공개됩니다. 비밀키를 넣으면 안 됩니다. Vite가 secret/service_role 형식 키를 발견하면 빌드를 거절합니다.

## 기능

- 자유·익명·질문·공부·분실물·동아리·투표 게시판
- 게시글/댓글 CRUD, 대댓글, 글별 익명 번호, 공감, 신고, 조회수
- 검색, 최신/인기 정렬, 일간/주간 인기글, 기기 내 임시 저장
- 투표 생성/참여 및 중복 투표 방지
- 댓글/답글/공지 알림, 읽음 처리 및 알림 설정
- 안남중학교 실제 NEIS 급식·학사일정, 본인 반 수행평가 일정과 수정 요청
- 관리자 통계·회원 검색/제한·신고 처리·게시물 삭제·공지·감사 기록
- 아이디 가입/로그인, 복구 코드 재설정, 비밀번호 변경, 프로필, 재인증 탈퇴
- 반응형, 라이트/다크 모드, 오류/로딩/빈 상태, 키보드 탐색

admin 계정은 사용자 요청에 따라 서버에서 관리자 지정했습니다. 기본 관리자 비밀번호나 자동 승격 규칙은 없습니다.

## 검증

    npm run lint
    npm test

    npm run test:e2e

    node tests/integration/live.mjs
    npx playwright test tests/e2e/live.spec.js --workers=1
    Remove-Item Env:\SCHOOLPOT_LIVE_TEST

## 구조

    src/components  공통 레이아웃
    src/config      학교 설정·DB 게시판 메타데이터 상태
    src/lib         안전한 DOM·아이디·입력 검증
    src/pages       인증·홈·커뮤니티·학교생활·관리자
    src/services    Auth/RPC/Edge 어댑터
    src/styles      디자인 시스템·반응형
    supabase/migrations  스키마·권한·버전별 SQL
    supabase/functions   accounts·neis·delete-account
    tests/unit·database·e2e·integration
    docs            설계·보안·배포·진행·검증

연결/Pages 배포는 docs/deployment.md, 검증 결과는 docs/verification.md, 보안 경계는 docs/security.md를 참고하세요. 파일 첨부·푸시 알림·사용자 차단 UI·V2/V3는 구현 범위 밖입니다. 정식 운영 정책과 이용약관/개인정보 처리방침은 운영자가 확정해야 합니다.

## 모바일·PC GUI

320~1440px 화면을 검증했습니다. PC 사이드바, 태블릿 아이콘 메뉴, 모바일 하단 메뉴·검색창, 계정 드롭다운, 비밀번호 보기, 터치용 입력창과 버튼을 제공합니다. 자세한 저장 구조는 docs/data-storage.md에서 확인할 수 있습니다.

## 관리자 팝업

관리자 대시보드의 팝업 관리에서 제목·본문·닫기 옵션을 등록하면 방문자에게 첫 진입 안내가 표시됩니다. 미리보기·수정·중지·재개·삭제를 지원합니다. 사용법과 브라우저별 보지 않기 동작은 docs/popups.md를 참고하세요.

## 게시판 관리와 건의·오류 제보

관리자 대시보드의 **게시판 관리**에서 게시판 추가, 이름·설명·순서 변경, 읽기 전용·숨김 설정과 빈 게시판 삭제를 지원합니다. 일반·항상 익명·투표 유형을 선택할 수 있으며 생성 후 주소와 유형은 고정됩니다. 글이 있는 게시판은 삭제 대신 숨김으로 보관합니다.

회원은 메뉴의 **건의·오류 제보**에서 문의를 보내고 내 문의의 상태와 답변을 확인합니다. 관리자는 **건의·오류 관리**에서 유형·상태별 조회와 답변을 할 수 있으며 변경 시 작성자에게 사이트 알림이 전달됩니다. 다른 회원에게는 문의를 공개하지 않습니다. 자세한 운영 방법은 [docs/management.md](docs/management.md)를 참고하세요.
