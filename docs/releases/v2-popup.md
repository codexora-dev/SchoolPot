## 앱 설치와 알림 설정을 확인해 주세요

스쿨팟의 새 기능은 [V2 업데이트 공지](#/notices)에서 확인할 수 있어요.

- [앱 설치 안내](#/app-install): 설치는 선택입니다. iPhone·iPad는 Safari 공유 메뉴에서 홈 화면에 추가해 주세요.
- [알림 설정](#/notification-settings): 종류별 수신과 방해 금지 시간을 설정하고, 지원되는 기기에서 직접 푸시 알림을 연결하세요.
- 업데이트는 작성 중인 내용을 저장한 뒤 직접 적용해 주세요.

연결이 끊겨도 게시글·계정 정보를 오프라인에 저장하지 않습니다. 공용 기기에서는 사용을 마친 후 로그아웃해 주세요.
