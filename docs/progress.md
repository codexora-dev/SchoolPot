## 요구사항 변경

사용자가 재학생 인증 신청 없이 회원가입하도록 변경했다. 신청 테이블·신청 UI·자동 승인·학생증 수집 없이 이메일 인증 회원제만 구현했다. 안내에도 재학생 확인을 하지 않는다는 점을 명시했다.

## 발견한 문제와 해결

1. 초기 ESLint 10 의존성에서 minimatch 관련 moderate 취약점 4건 확인. 취약점이 없는 ESLint/@eslint/js 9.39.5 조합을 고정하고 lockfile을 저장했다. ESLint 9의 지원 종료 경고는 남아 있으므로 향후 ESLint 10 의존성 수정 확인 후 업그레이드한다. npm audit은 현재 0건이다.
2. 수행평가 UI 초기 중첩 DOM 표현의 괄호 오류를 빌드에서 발견하고 반복문 기반 생성으로 정리했다. 재빌드/린트 통과.
3. Playwright 실행용 브라우저 미설치로 첫 실행 실패. Chromium을 설치한 뒤 재실행해 통과했다.
4. 댓글 응답을 페이지당 50개로 제한하고 이동을 추가했다. 탈퇴 후 남은 토큰을 계정 존재 확인으로 거절하도록 구현했다.
5. 이용 제한 회원이 탈퇴할 수 있도록 me/delete_account_access에 한해 제한 검사를 예외 처리했다. 커뮤니티 접근은 계속 거절한다.
6. 빈 토스트가 첫 캡처에서 잠깐 보일 수 있어 :empty는 숨기도록 처리했다. 아이콘 버튼에 접근성 레이블을 추가했다.
7. Supabase 도구의 프로젝트 접근 권한 오류 발생. 권한을 우회하거나 서비스 키를 요청하지 않고 로컬 구현을 계속했다. 전달받은 공개 키로 원격 RPC의 미설치(PGRST202)를 확인했으며 DDL은 실행하지 않았다.

## 2026-11-12 관리자 사이트 진입 팝업

사이트 진입 팝업 등록/수정/중지/재개/삭제·미리보기와 기본/오늘 하루/다시 보지 않기 옵션을 구현했다. public projection은 게시된 제목·본문 등 최소 필드만 반환하고, 관리 API는 기존 인증·세션·계정·관리자 권한과 요청 제한을 재사용한다. RLS·작성자 비노출·기본 닫기 강제·최대 3개 활성 팝업·오래된 수정 거절·감사 기록을 적용했다.

DB 마이그레이션을 원격 적용하고 비회원 조회 200/관리 거절 401을 확인했다. 로컬 입력/선호도 15개, DB 48개, 브라우저 30개를 통과했다. 실제 임시 QA 계정으로 일반 권한 거절·비공개 생성·수정·버전·옵션 검증·삭제 7개를 통과하고 계정/팝업 잔여 0건을 확인했다. 활성 공개 조회는 실제 DB 역할 및 롤백 트랜잭션으로 검증해 방문자에게 테스트 내용을 게시하지 않았다.

같은 페이지를 자정 너머 유지할 때 오늘 하루 설정이 만료될 수 있도록 지속 저장 성공 시에는 방문 메모리로 중복 숨김하지 않게 했다. 관리자/방문자 테스트 fixture와 실제 서버 검증을 분리했다. Security Advisor에서 Auth 유출 비밀번호 보호 비활성 WARN 1건을 새로 확인하여 문서화했으며 유료 설정을 임의 변경하지 않았다.

## 2026-11-12 자동로그인·눈 아이콘·회원탈퇴

로그인 화면에 기본 미선택 자동로그인을 추가했다. 선택한 경우만 Supabase 토큰을 영구 저장하고 미선택 시 탭 세션으로 유지한다. 비밀번호를 보관하지 않으며 성공한 로그인 이후 저장 방식을 적용한다. 해제/로그아웃/탈퇴 시 영구 인증 정보와 선택을 제거한다. 기존 선택 없는 영구 토큰은 정리하고 재로그인하도록 했다. 저장소 차단·용량 부족은 메모리/탭 저장으로 대체하고 자동로그인 유지 불가를 알린다. 선택 플래그만 저장되고 토큰 저장이 실패하는 경우도 검사했다.

기존 텍스트형 비밀번호 보기 버튼을 오른쪽 끝의 눈/가린 눈 SVG로 변경했다. aria-label/pressed/controls와 44px 클릭 영역을 적용하고 Enter/Space로 표시/숨기기를 지원한다. 모든 비밀번호 필드에 공통 적용했다.

계정 메뉴에 계정 관리 · 회원탈퇴 진입을 추가하고 기존 탈퇴 로직을 공통 대화상자로 정리했다. 확인 문구와 현재 비밀번호, 실제 Edge 응답 확인, 구체적인 비밀번호 오류, 중복 제출/처리 중 닫기 차단, 탈퇴 후 인증·자동로그인·개인 임시 글 정리를 적용했다. Edge 함수의 비밀번호 재인증/전역 세션 취소/삭제 기능은 기존 구현을 유지했다. UI에서 게시글·댓글·문의 본문 보존을 알린다.
