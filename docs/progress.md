관리자 PC 사이드바/모바일 가로 메뉴, 중요 공지 권한 UI, 민감 문의 이관, 최고 관리자 서비스 표시 정보, 규정 버전 게시/원문 보존, 실제 RLS 집계 및 감사 사유 표시를 구현했다. 관리자 메뉴는 데이터 로드 전에 허용 여부를 확인한다. 새 API 읽기 타임아웃은 조회에만 적용하고 제재·정책 변경을 자동 재시도하지 않는다.

검증 중 SQL 변수와 열 이름 충돌을 발견해 변수를 분리했다. 소스 검사 테스트의 문자열 spread로 코드가 커지면 스택이 넘치는 기존 문제를 수정했다. 규정 탭/관리자 제목의 기존 회귀 검사 차이를 맞췄고, 연속 접근 상태 확인이 누락되는 경쟁 조건은 후속 확인 큐로 수정했다. E2E는 클릭 직후 비동기 요청 완료 전에 fixture를 읽던 경쟁을 대화상자 완료 대기로 수정했으며, 스크린샷은 로딩 종료 후 캡처하도록 보완했다.
