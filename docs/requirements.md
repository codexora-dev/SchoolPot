# V1 요구사항 및 완료 조건

사용자 최신 결정: 학생 인증 신청을 받지 않고 이메일 회원가입을 제공한다. 이메일 인증 후 이용하며 재학생 여부는 확인하지 않는다. 학생 인증 화면·신청 테이블은 의도적으로 제외했다.

| 영역     | 로컬 구현                                                                                          | 운영 완료 조건/남은 작업                                              |
| -------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 회원     | 가입·메일 인증 연계·로그인/로그아웃·세션·비밀번호 재설정·닉네임/학년·탈퇴                          | Auth 설정, SMTP 발송·PKCE 리다이렉트·재설정 실제 검증, 탈퇴 함수 배포 |
| 게시판   | 자유·익명·질문·공부·분실물·동아리·투표                                                             | 원격 마이그레이션 후 실계정 검증                                      |

제목/본문 검색은 부분 문자열 검색이며, 결과는 페이지당 20개다. 최근 인기글은 24시간/7일 이내 작성 글의 누적 공감순이다. 수행평가 캘린더는 날짜별 리스트 형식이다. 학사일정은 NEIS 실시간 프록시로 조회하므로 별도 중복 DB를 두지 않는다. 임시 저장은 사용자별 기기 로컬 저장이고 클라우드 동기화하지 않는다.

별도 미구현/미확정: 사용자 차단 UI, 첨부파일, 실시간/푸시 알림, 전체 회원 대상 공지 알림 대량 배치, V2/V3, 정식 이용약관·개인정보 처리방침·운영자 연락처·연령별 동의 절차. 공개 운영의 선행 조건으로 남겨둔다.

테스트 상세와 단계별 결과는 `progress.md`에 기록한다. 로컬 테스트 통과를 실제 서비스 운영 완료로 표시하지 않는다.
