# V1 구현 상태

최신 사용자 결정: 안남중학교를 대상으로 아이디·8자 이상 비밀번호와 본인 학년·반으로 가입한다. 소속 선택에는 동의·연령 체크를 요구하지 않으며 확인 기록을 임의 생성하지 않는다. 이메일·재학생 인증 신청·생년월일은 받지 않는다. 수행평가는 본인 반으로만 제한하고 반 수는 관리자가 설정한다. 보유기간은 탈퇴 시 삭제로 변경했다. 문서 검토 상태는 가입 차단과 분리하며 실제 연령·소속 확인이나 법적 적합성을 보장한다고 표시하지 않는다.

| 영역      | 구현/검증                                                                                                            |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| 계정      | 아이디 가입·로그인·세션·자동 프로필·닉네임/학년·현재 비밀번호 재인증 변경·복구 코드 재설정·탈퇴, 실제 서버/화면 검증 |
| 커뮤니티  | 7개 게시판, 글·댓글 CRUD, 1단계 답글, 공감·신고·조회수·검색·정렬·임시 저장                                           |
| 익명      | 작성자 UUID 비노출, 글별 익명 번호, 서버 소유권·관리자 검사                                                          |
| 투표/알림 | 1인 1표, 중복 방지, 댓글/답글/공지 알림·읽음·설정                                                                    |
| 학교생활  | 안남중학교 실제 NEIS 급식·학사일정, 학년별 날짜 그룹 캘린더·수행평가 등록/수정/삭제·수정 요청                        |
| 관리자    | 지정 admin 계정, 통계·회원 검색/제한·게시물 관리·신고/수정 요청 처리·공지·감사 기록                                  |
| 디자인    | 라이트/다크, 반응형, 키보드 레이블, 로딩/오류/빈 상태                                                                |
| 원격      | DB 마이그레이션 4개와 Edge 함수 3개 적용, 실제 API 15개 및 실제 UI 흐름 검증                                         |
| 배포      | GitHub main, SchoolPot Pages 공개 배포·자동 재배포·저장소 경로·CSP·배포 후 자산 검사                                 |

검색은 부분 문자열, 글 20개/댓글 50개 단위 페이지다. 인기글은 24시간/7일 이내 작성 글의 공감순이다. 임시 글은 기기 로컬에만 저장한다. 수행평가 캘린더는 날짜별 리스트이고 학생 공유 정보이므로 과목 선생님의 최종 안내를 따른다.

추가 범위: 첨부파일·푸시 알림·사용자 차단 UI·V2/V3, 대량 알림 배치, 정식 운영 정책/실제 문의 수신·처리업체 고지 검토, 연령·소속의 실제 인증, 만 14세 미만 보호자 동의 확인, 복구 코드 분실 시 본인 확인 정책. 완료되지 않은 운영 준비를 검증 통과로 표시하지 않는다.

## 관리자 팝업

제목/본문 등록, 닫기 옵션 선택, 미리보기, 수정, 게시 중지/재개, 삭제를 구현했습니다. 사이트 첫 진입에 공개 안내를 표시하고 기본 닫기·한국 날짜 기준 오늘 하루·브라우저별 다시 보지 않기를 지원합니다. 수정 시 새 버전으로 표시하며 기본 닫기는 항상 유지합니다. 로컬·실제 서버 검증과 상세 사용법은 popups.md 및 verification.md에 기록합니다.
