# 반별 수행평가와 개인정보 운영

2026-11-13 최신 결정: 회원가입과 기존 회원의 학년·반 선택에 개인정보 동의·연령 확인 체크를 요구하지 않습니다. 학생 실명·학번·학생증·생년월일·실제 이메일은 수집하지 않습니다. 소속은 자기 신고이며 실제 재학생 인증이 아닙니다. 새 계정의 연령 확인 시각은 null입니다.

관리자가 학년도와 학년별 마지막 반 번호를 설정합니다. 0은 해당 학년 등록 중지입니다. 운영 설정 [7,7,7]을 초기화하지 않습니다. 개인정보 문서 검토 상태는 가입·소속 등록을 차단하지 않습니다. 현재 공개 문서와 문의 이메일은 관리자에서 수정합니다.

회원은 같은 학년도에서 임의로 반을 변경할 수 없습니다. 관리자 정정은 사유와 이전/이후 소속을 감사 기록으로 남기고 회원에게 알립니다. 새 학년도에는 새 소속을 등록합니다. 수행평가의 조회·등록·수정·신고는 요청 필터 대신 auth.uid()에 연결된 DB 소속으로 제한합니다. 관리자에게도 다른 반 본문 조회 예외가 없습니다. 반 미지정 기존 일정은 작성자만 이관·삭제할 수 있습니다.

새 기록은 collection_basis=service_contract와 안내 시각을 저장합니다. 동의·국외 처리 동의 시각은 null이며 허위 동의를 만들지 않습니다. 기존 실제 동의는 원래 문서 버전과 보존합니다. 문서 변경으로 기존 소속을 차단하거나 반 변경을 허용하지 않습니다.

사용자 요청으로 개인 이메일은 현재 소스·현재 정책 및 보관 정책 문서에서 삭제했습니다. 공개 처리방침에서 위탁·국외 처리·보안 기록과 문의·권리행사 섹션을 제거했고 가입의 처리 안내 문구·링크도 제거했습니다. 기존 Git 커밋과 제3자 복제·캐시·외부 백업 삭제까지 보장하지 않습니다.

탈퇴 시 운영 DB의 계정·소속·기존 동의·계정 연결 작성 내용을 삭제합니다. 본인 게시글의 타인 답글도 함께 삭제될 수 있습니다. 외부 업체 로그·백업까지 즉시 완전 삭제한다고 보장하지 않습니다. 보안 카운터는 기존의 7일 경과분 후속 요청 정리 방식이며 엄격한 최대 7일 보유라고 표시하지 않습니다.

필수 서비스 정보를 동의 체크 없이 처리하도록 기술 구조를 변경했습니다. 모든 처리의 적법성을 보장하는 것은 아닙니다. 실제 운영 주체·처리업체·국외 처리·보유기간·권리행사 절차는 운영자가 확인해야 합니다. 관리자 문서 검토 체크는 법적 검토를 대신하지 않습니다.
