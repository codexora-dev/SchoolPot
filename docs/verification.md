총 85개 검사 통과. 기본 E2E에서는 실제 계정을 만드는 1개 검사를 의도적으로 건너뛰고, 별도 SCHOOLPOT_LIVE_TEST=1 실행으로 통과를 확인했습니다. fixture 검증과 실제 서버 검증을 구분했습니다.

실제 API 검사는 8자리 비밀번호 가입·이메일 인증 없는 로그인·자동 프로필·익명 UUID 비노출·권한 우회 거절·공감/투표 중복 방지·댓글 알림·학년 일정·실제 안남중학교 급식·복구 코드 회전·이전 세션 차단·탈퇴를 포함합니다. 만든 QA 계정과 게시물/일정은 삭제했습니다. 이후 사용자가 만든 admin 계정은 유지하고 사용자 지정에 따라 관리자 역할을 부여했습니다.

프로덕션 /SchooltPot/ 하위 경로를 별도 브라우저에서 실행해 signup 화면·아이디 필드·CSP·자바스크립트 오류 부재를 확인했습니다. npm run lint/build와 Edge 함수 타입 검사를 통과했고 npm audit에서 알려진 취약점 0건을 확인했습니다.

Supabase Security Advisor에는 ERROR/WARN이 없고 private 테이블 23개의 RLS enabled/no policy INFO만 있습니다. 이는 허용 정책과 직접 테이블 권한을 주지 않는 기본 거부 설계이며, 허용 정책을 추가해 해제하지 않습니다.

정식 운영 전 추가 검증: 다중 사용자 부하, 긴 기간 NEIS 사용량, 운영 정책/보존기간/본인 확인, 공개 호스팅의 응답 헤더와 관리자 본인 계정 UI 확인. GitHub Pages는 수동 배포 준비 상태입니다.
