# 관리자 팝업 사용 안내

관리자 로그인 후 **관리자 대시보드 → 팝업 관리**에서 등록합니다.

1. **＋ 팝업 등록**을 누릅니다.
2. 제목(2~120자)과 본문(1~8000자)을 입력합니다.
3. 방문자에게 제공할 닫기 옵션을 선택합니다. 기본 닫기는 항상 제공됩니다.
4. **등록 후 바로 게시**를 켜고 **팝업 등록**을 누르면 방문자에게 표시됩니다. 끄면 비공개로 저장합니다.
5. **미리보기**는 저장·게시하거나 보지 않기 설정을 기록하지 않습니다.

## 닫기 동작

- **닫기 / × / Escape:** 현재 페이지 방문 동안 닫습니다. 메뉴 이동이나 테마 변경으로 다시 열리지 않지만, 새로고침하거나 새로 방문하면 다시 표시됩니다.
- **오늘 하루 보지 않기:** 한국 시간의 해당 날짜 동안 이 브라우저에서 숨깁니다.
- **다시 보지 않기:** 같은 팝업 버전을 이 브라우저에서 계속 숨깁니다.

보지 않기 설정은 계정 전체가 아닌 브라우저별입니다. 저장소가 차단된 브라우저에서는 이번 방문에만 닫고 저장할 수 없다는 안내를 표시합니다.

## 수정과 게시 관리

수정·게시 중지·다시 게시·삭제를 지원합니다. 제목·본문·닫기 옵션을 바꾸면 버전이 올라가며, 이전 버전을 숨긴 방문자에게도 새 안내로 다시 표시됩니다. 게시 중지와 재개만으로는 버전이 바뀌지 않습니다. 수정 도중 다른 관리자가 내용을 변경하면 덮어쓰기 대신 새로고침을 요청합니다.

동시에 최대 3개까지 게시할 수 있으며 최신 순으로 하나씩 표시됩니다. 팝업은 최대 100개까지 보관할 수 있습니다. 관리자 작업 화면에는 자동 팝업을 띄우지 않습니다. 일반 페이지에 새로 진입하면 로그인 전 방문자에게도 표시되므로 공개할 수 있는 내용만 작성하세요.

## 저장 및 보안

private.site_popups에 저장하고, 공개 읽기 RPC는 게시 중인 팝업의 제목·본문·닫기 옵션·버전·팝업 ID만 반환합니다. 작성자 UUID와 비공개 팝업은 공개하지 않습니다. 등록·수정·삭제는 현재 계정·세션·DB 관리자 역할을 서버에서 검사하고 감사 기록을 남깁니다. HTML은 실행하지 않고 텍스트로 표시합니다.

이번 검증에서는 실제 서버에 비공개 QA 팝업만 만들고 정리했습니다. 활성 팝업 조회는 롤백 트랜잭션으로 확인했으며 테스트 안내를 실제 방문자에게 게시하지 않았습니다.

# Text / Markdown / HTML 작성

관리자에서 작성 형식을 선택하고 본문을 입력합니다. Text는 줄바꿈을 그대로 표시하며 Markdown/HTML은 제목·강조·목록·표·코드·링크·이미지를 렌더링합니다. 이미지는 공개 접근 가능한 HTTPS URL을 사용합니다. 이미지 파일 업로드 기능은 포함되지 않습니다. 본문 미리보기 또는 전체 팝업 미리보기에서 확인한 뒤 저장하세요. 공지 등록 화면도 동일한 작성기와 본문 미리보기를 사용합니다.

기존 내용은 text로 유지합니다. 팝업 형식만 바꿔도 새 revision으로 처리하여 이전 보지 않기 선택과 분리합니다. 공개 팝업에 작성자 정보는 추가하지 않습니다. 실행 코드·이벤트 속성·임의 CSS·iframe 등은 제외하며 일반 사용자 글·댓글의 HTML 실행을 허용하지 않습니다.
